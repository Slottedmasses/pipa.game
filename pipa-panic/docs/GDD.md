# 《琵琶曲：一腚定音》游戏设计文档

版本：0.1 原型  
类型：竖屏卡通打靶 / 轻肉鸽 / 分数挑战  
平台：微信小游戏（主）+ 浏览器预览  
单局时长：75 秒 + 商店暂停  
目标用户：喜欢短视频梗、射击手感、轻量成长和收集的中文用户

---

## 1. 一句话

按住屏幕瞄准，射击一个又一个撅着屁股的「接弹人」；打臀双倍伤害、双倍金币，金币既能当场买肉鸽强化，也能带出去升级枪械、解锁牛来 / 肥嘟嘟 / 豆包皮肤。

## 2. 体验支柱

1. **一眼就懂**：屏幕中央一个屁股，准星移上去就出现「打臀 ×2」。
2. **每枪有反馈**：枪口火焰、弹道、金币、伤害数字、屏幕震动、角色怪叫、手机轻震。
3. **每 10 秒有选择**：KO → 三选一肉鸽 → 换一个更厚的接弹人 → 继续打。
4. **每局有一点成长**：金币永久保留，升级枪、买皮肤，下一局更强/更好看。
5. **不血腥、不下流**：全部卡通化，角色穿衣服，无血液伤口，靠夸张表情和拟声词制造笑点。

## 3. 核心循环

```
主菜单
  → 开始演奏（75 秒）
    → 瞄准 / 连射 / 打臀
      → 造成伤害 + 获得金币 + 累积 Combo
        → 血条清空
          → KO（+2.5 秒）→ 军火商三选一
            → 下一位接弹人（血量更高）
              → 循环，直到时间归零
                → 结算（分数 / 评级 / 金币）
                  → 升级枪械 / 解锁皮肤 / 再开一局
```

局内追求：高分、高 Combo、高打臀率、尽可能多换人。  
局外追求：枪械满级、四套皮肤、最高分、历史最佳打臀率。

## 4. 操作与瞄准

- 触摸/鼠标按下：开始连射，准星跟随手指/鼠标。
- 移动：持续瞄准；按住期间自动按射速开火。
- 松开：停火。
- 空弹匣：自动装填；也可以按 `R` 手动装填。
- 桌面端：`Space` 开火，`P/Esc` 暂停，`M` 静音，`Enter` 确认。

### 为什么采用「按住连射」而不是「点一下打一枪」

- 短视频梗的爽点是「连续被子弹轰」，连射更贴合。
- 手机上减少重复点击疲劳。
- 把操作复杂度留给「瞄准屁股」和「什么时候买什么强化」，而不是手速。
- 换弹制造节奏断点，让音乐和枪声有呼吸。

### 命中判定

角色以脚底为原点，整体绕脚底轻微摇摆；命中检测转换到角色局部坐标后进行。

| 部位 | 椭圆中心（局部） | 半径 | 倍率 |
|---|---|---:|---:|
| 头 | (-44, -358) | 44 × 47 | 0.62× |
| 屁股 | (0, -222) | 78 × 58（受「臀部雷达」放大） | 2.0× 起 |
| 躯干 | (-4, -300) | 60 × 78 | 1.0× |

屁股判定比视觉略大，保证移动端手指遮挡时仍可命中。头部倍率故意压低，并用「别打脸」吐槽把玩家引导回屁股。

## 5. 伤害、金币与分数

### 5.1 单发伤害

```
基础伤害 = 22 + 枪械等级 × 4
最终伤害 = 基础伤害
         × 部位倍率
         × (1 + 枪管抛光等级 × 0.22)
         × (暴击 ? 1.8 : 1)
```

- 初始 Lv.1：26 伤害。
- 打臀基础 2.0×，即 52 伤害。
- 暴击率初始 7%，每级暴击火药 +7%，豆包皮肤 +6%。
- 黄金臀期间打臀额外 +1.1×。

### 5.2 金币

```
单次金币 = 部位基础金币
         × (1 + 金币嗅觉 × 0.25)
         × (1 + 皮肤金币加成)
         × (1 + min(Combo, 40) × 0.02)
         × (黄金臀 ? 2 : 1)
```

部位基础金币：屁股 5、身体 2、头 1。

- Combo 金币系数最高 1.8×。
- 实测一局正常游玩约 800–1,600 金币；全打臀的自动化测试一局约 3,200 金币。
- KO 奖励 80 + 波次 × 35 金币。
- 结算完成奖励 50 + 波次 × 20 金币。
- 商店「跳过」奖励 25 金币。

### 5.3 分数

```
单次得分 = 伤害 × 8.2 × Combo 系数 × 皮肤得分加成 × (打臀 ? 1.25 : 1)
KO 得分 = 800 + 波次 × 280
```

评级阈值：

| 评级 | 分数 | 称号 |
|---|---:|---|
| SSS | ≥ 150,000 | 琵琶武神 |
| S | ≥ 100,000 | 铁臀判官 |
| A | ≥ 65,000 | 神枪手 |
| B | ≥ 35,000 | 见习枪手 |
| C | < 35,000 | 手抖患者 |

自动化全打臀测试一局 279,127 分，属于 SSS；真人正常命中率下，A/S 是主要目标区间。

## 6. 接弹人与波次

```
最大生命 = 1500 + (波次 - 1) × 750 + (波次 - 1)² × 120
```

| 波次 | 最大生命 | 预计击杀时间（基础 DPS） |
|---|---:|---:|
| 1 | 1,500 | 7–10 秒 |
| 2 | 2,370 | 10–13 秒 |
| 3 | 3,480 | 14–18 秒 |
| 4 | 4,830 | 18–24 秒 |
| 5 | 6,420 | 22–30 秒 |

- 每次 KO 后时间 +2.5 秒、进入商店、换下一位。
- 血量低于 35% 时进入「急眼」状态，摆动速度提高约 30%。
- 目标左右摆动 ±43 px，叠加轻微呼吸和旋转；命中时会短暂踉跄。
- 每 4.5–7.5 秒说一句垃圾话（「就这？」「没吃饭？」等）。

## 7. 黄金臀

- 每 9–13 秒触发一次，持续 2.7 秒。
- 屁股发出金色光晕，屏幕轻微金色脉冲，HUD 显示倒计时条。
- 打臀倍率额外 +1.1×，金币 ×2。
- 触发时角色喊「黄金臀！快打！」，并弹出金色浮字。
- 设计目的：给连续射击一个短周期的「值得等」的高光时刻，也让玩家愿意把子弹留到黄金窗口。

## 8. 肉鸽强化

每次 KO 后从可用池中随机 3 张；每张有等级上限，价格随等级增加。

| key | 名称 | 效果 | 上限 | 基础价 |
|---|---|---|---:|---:|
| damage | 枪管抛光 | 伤害 +22% | 6 | 90 |
| rate | 快手扳机 | 射速 +12% | 6 | 90 |
| buttRadar | 臀部雷达 | 打臀判定 +14% | 4 | 110 |
| buttMult | 双倍快乐 | 打臀倍率 +0.5× | 3 | 150 |
| gold | 金币嗅觉 | 金币 +25% | 5 | 100 |
| crit | 暴击火药 | 暴击率 +7% | 5 | 120 |
| mag | 扩容弹巢 | 弹匣 +2 发 | 4 | 80 |
| echo | 余音绕梁 | 15% 不耗弹 | 3 | 100 |
| double | 双管齐下 | 12% 追加一颗 | 3 | 140 |

- 价格公式：`基础价 + 当前等级 × 35`。
- 所有强化只在本局生效，开局重置。
- 当可选强化不足 3 张时，用「应急赏金：免费 +70 金币」补齐。
- 购买后立即关闭商店、刷出下一位接弹人；买不起可以跳过拿 25 金币。
- 设计意图：让玩家在「稳定伤害 / 打臀收益 / 暴击 / 弹匣」之间做取舍，避免每局都点同一个最优解。

## 9. 局外成长

### 9.1 枪械

- Lv.1–Lv.12。
- 每级基础伤害 +4。
- 升级费用：`160 + (当前等级 - 1) × 140`。
- 满级基础伤害 70。

| 等级 | 基础伤害 | 升下一级费用 |
|---|---:|---:|
| 1 | 26 | 160 |
| 2 | 30 | 300 |
| 3 | 34 | 440 |
| 4 | 38 | 580 |
| 5 | 42 | 720 |

### 9.2 皮肤

| 皮肤 | 价格 | 被动 | 视觉关键词 |
|---|---:|---|---|
| 西装暴徒 | 免费 | 无 | 黑西装、红领带、油头、白衬衫领口 |
| 牛来 | 600 | 得分 +12% | 橘黄牛头、深棕弯角、肉色口鼻、木讷眼神、牛尾 |
| 肥嘟嘟 | 1400 | 金币 +12% | 黄色袋鼠、长耳、大鼻、龅牙、黑短裤、粗尾巴 |
| 豆包 | 2400 | 暴击 +6% | 白色豆形机器人、青色面罩、天线、白色装甲臀 |

- 皮肤只改变外观和一个小被动，不改变核心操作。
- 购买后永久拥有，并在主菜单切换。
- 皮肤可以通过 `?demo=1` 全部体验。

## 10. 经济曲线

目标：第一局结束能买到第一把枪升级或第一次皮肤；2–4 局解锁全部内容。

| 来源 | 每局大约 |
|---|---:|
| 打臀金币 | 500–1,200 |
| 身体/头部金币 | 100–300 |
| KO 奖励 | 400–700 |
| 跳过商店 | 0–125 |
| 结算奖励 | 70–150 |
| **合计** | **约 1,000–2,500** |

| 支出 | 价格 |
|---|---:|
| 一局内 3–5 张强化 | 300–600 |
| 枪械 Lv.1→5 | 约 2,280 |
| 牛来 | 600 |
| 肥嘟嘟 | 1,400 |
| 豆包 | 2,400 |

设计上允许玩家在「先买皮肤」和「先升枪」之间选择；皮肤价格略高，作为长期收集目标。

## 11. 状态机

```
menu
  ├─ start → playing
  │    ├─ pause → paused → resume → playing
  │    │                 └─ endRun → result
  │    ├─ target hp = 0 → ko（1.55s，时间暂停，角色扑倒）
  │    │                    └─ openShop → shop
  │    │                                   ├─ buyCard → playing（下一波）
  │    │                                   └─ skip → playing（下一波）
  │    └─ time = 0 → losing（2.95s 反杀过场，可点击跳过）
  │                         └─ finishLose → result
  └─ modal(skin purchase)
```

- `shop` 和 `ko` 期间不倒计时。
- `losing` 期间暂停倒计时和 BGM，播放视频过场的原声；点击可跳过。
- `result` 保存最高分、历史连击、最佳打臀率、游玩次数；失败局会带「被反杀」标记。
- `paused` 期间暂停 BGM 音量但不完全停止；返回时恢复。
- 切后台/浏览器隐藏时自动暂停并写存档。

## 13. 美术方向

- **色调**：深酒红、黑、旧金色、奶油白；青色只用于豆包和机器人科技感。
- **场景**：参考视频里的红色旧房间、木地板、吊灯、破墙和暖色体积光；游戏内用视频景深帧 + 中央红丝绒幕布 + 透视地板重建舞台。
- **角色**：**2.5D 伪 3D 卡通渲染**。球面/柱面渐变、顶部主光、左右边缘光、环境遮蔽、接触阴影、高光反射、随瞄准的轻微视差。不是 flat vector。
- **枪**：第一人称金色左轮，红印章「臀」，枪口火焰和烟雾。
- **字体**：标题用楷体/宋体回退，正文用苹方/微软雅黑回退。
- **动效**：呼吸、摆动、命中侧倾、手臂甩动、头部偏转、屁股晃动、金币喷发、屏幕震动、KO 扑倒。
- **失败过场**：从参考视频抽取 15 帧竖屏关键帧，拼成 5×3 精灵表；播放「接弹人从身后掏枪 → 枪口对准镜头 → 开枪 → 玩家倒下」的序列，叠加录像回放 UI、扫描线、字幕和原声。
- **审查安全感**：无血、无伤口、无骨骼、无死亡细节，角色始终穿衣服，场景是舞台而不是卧室；失败过场用「录像回放」框定，避免写实暴力。

### 13.1 视频背景处理

- 从 `素材2.mp4` 提取房间帧，裁成 9:16，做高斯景深、压暗、红色调色、中心遮罩和颗粒。
- 保留视频里的吊灯、红墙、床垫、木地板和光斑作为景深信息。
- 中央用程序化幕布和前景地板遮住原片角色的位置，避免和新的 3D 角色重叠。
- 视频层随瞄准做 1–2 px 视差，并缓慢缩放，制造镜头深度。

## 14. 音频

- **BGM**：用户提供视频提取的《琵琶曲》混音，循环播放；音量 0.44，商店/结算降到 0.18。
- **失败过场**：`assets/cutscene/lose-sting.mp3`，从 `素材3.mp4` 的 3.55–5.75s 提取，含枪声和原片环境声；进入 `losing` 时暂停 BGM 并播放。
- **音效**：Web Audio 合成，不依赖音频文件：
  - 枪声：噪声 + 低频三角波 + 方波；
  - 打臀：低频正弦下扫 + 高频三角波 + 短噪声；
  - 金币：两个高频正弦；
  - 装填：两下短方波；
  - 暴击：三角波上扫；
  - KO：低频长音 + 噪声。
- **微信端**：优先 `wx.createWebAudioContext()`；不支持则静默，不阻塞游戏。
- **静音**：写入存档，重进保持。

## 15. 技术架构

- 单文件 `game.js`，IIFE 封装，无构建步骤。
- 同一份代码在浏览器和微信小游戏运行：
  - 画布：`wx.createCanvas()` / `document.getElementById('game')`；
  - 触摸：`wx.onTouchStart` / Pointer Events；
  - 音频：`wx.createInnerAudioContext` + `wx.createWebAudioContext` / `<audio>` + Web Audio；
  - 存储：`wx.getStorageSync` / `localStorage`。
- 逻辑分辨率 390×844，`contain` 缩放居中，DPR 上限 3。
- 程序化背景缓存到 offscreen canvas；视频景深层、幕布、地板、动态层每帧绘制。
- 图片资源：`wx.createImage()` / `new Image()` 预加载 `bg-video-main.jpg` 和 `lose-sheet.jpg`；失败过场用一张 5×3 精灵表，避免同时解码 15 张图。
- 游戏循环：`requestAnimationFrame`，`dt` 上限 50ms，避免切后台后大跳。
- 状态：`menu / playing / losing / shop / paused / result` 由 `game.scene` 控制；`ko` 仍在 `playing` 内由 `run.ko` 标记。
- 输入：每帧重建按钮命中区，按下时从后往前查找，弹窗层过滤，避免穿透。
- 存档：`SAVE_KEY = pipa-panic-save-v1`；不采集个人信息。

## 17. 上线改造建议

### 低风险版

- 目标改成 **训练机器人 / 沙袋 / 铁臀靶**，不做人类。
- 枪改成 **橡胶弹发射器 / 训练枪**。
- 「打屁股」改「打靶心」，保留双倍判定和金币。
- 去掉扭动、撅臀等性暗示动作，改成机械靶旋转。
- 皮肤改成原创机器人：牛仔、袋鼠、豆包形机器人。
- 标题改《铁臀训练营》或《一腚定音·训练场》。

### 标准版

- 保留现在的角色和笑点，但拿到音乐、角色 IP 授权。
- 增加年龄提示和内容说明。

# 参考素材说明

本目录的 `contact1.jpg`、`contact2.jpg`、`contact3.jpg` 分别从用户提供的 `素材1.mp4`、`素材2.mp4`、`素材3.mp4` 中按 1 fps 抽帧，并以 5×5 拼图生成，仅用于分析：

- 暗红色旧剧院/房间的布景；
- 黑西装射击者与第一人称左轮；
- 穿黑色紧身衣、撅着屁股接子弹的角色；
- 夸张的命中表情与镜头晃动。

游戏没有使用这些视频的画面、模型或贴图；只把「琵琶曲 + 打屁股接子弹」的梗和整体氛围作为灵感。

背景音乐 `assets/audio/pipa-theme.mp3` 从用户提供的 `素材2.mp4` 提取，仅用于原型演示。公开报道提到该梗常用曲目为方浩《琵琶曲》的 DJ 版本；正式发行前请替换为已授权音乐或原创曲目。
